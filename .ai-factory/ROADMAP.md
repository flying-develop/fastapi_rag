# Roadmap проекта

> Поэтапная разработка AI-сервиса на FastAPI + LangChain/LangGraph:
> от диалогов и RAG до task pipeline и модерации контента.

## Вехи

- [x] **Bootstrap проекта** — скелет FastAPI-приложения (uv, `app/infrastructure/config.py` на pydantic-settings), docker-compose (app + PostgreSQL + Redis + Qdrant), структурированное логирование, `/health`-эндпоинт.
- [x] **Фундамент работы с БД** — SQLAlchemy 2.0 (async) engine/session, Alembic-миграции, первый модуль (`dialog`) со сквозным CRUD через repository-паттерн — база для остальных модулей.
- [x] **Диалоги с LLM (базовый чат)** — модели `Dialog`/`DialogMessage`, интеграция с LangChain chat-моделью (OpenAI), эндпоинт отправки сообщения с сохранением истории в PostgreSQL.
- [x] **Tool calling у LLM (Pydantic-инструменты)** — модель не просто генерирует текст, а вызывает инструменты-функции; параметры и результат вызова описаны Pydantic-схемами (structured output). Базовый паттерн на простом примере — переиспользуется в следующих вехах для получения данных (БД, RAG-поиск, внешние API) и других фич, а не только в диалоге.
- [ ] **Диалог как граф LangGraph** — перевод логики диалога на LangGraph (узлы/рёбра, состояние разговора, вызов инструментов из графа) вместо линейного вызова LLM — первое знакомство с LangGraph.
- [ ] **Работа с файлами** — приём файлов, S3-совместимое хранилище, парсинг PDF/DOCX/XLSX в текст.
- [ ] **RAG: индексация статей** — чанкинг текста, генерация embeddings, upsert в Qdrant.
- [ ] **RAG: поиск и ответ с источниками** — retriever + rerank + формирование ответа LLM со ссылками на источники, интеграция с диалогом.
- [ ] **Task pipeline на LangGraph** — модели `Task`/`TaskStep`/`TaskResult`, конвейер как граф состояний.
- [ ] **Фоновые задачи и колбэки** — ARQ-воркер, вынос RAG-индексации и обработки задач в фон, колбэк о результате.
- [ ] **Модерация контента (первый конвейер)** — один вид модерации (например, сообщения) как LLM-классификация с кодами ошибок, поверх паттерна task pipeline.
- [ ] **Остальные конвейеры модерации** — модерация профиля, аватара, файлов профиля, модерация проектов, "хочу"-заявки — по образцу первого конвейера.
- [ ] **API-ключи и контексты доступа** — разграничение доступа внешних клиентов по ключам/контекстам.
- [ ] **Устойчивость и наблюдаемость** — единый формат ошибок API, тестовое покрытие ключевых модулей, финальная полировка логирования.
